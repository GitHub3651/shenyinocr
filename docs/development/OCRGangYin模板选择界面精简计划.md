## 1. 状态与权威范围

- 状态：代码实施完成，待用户统一验证。
- 权威范围：模板选择窗口、模板路径的批量引用移除、多模板最高分选择的当前说明。
- 当前进度：阶段 A～E 的生产代码、当前行为文档和静态门禁均已完成；未执行 Qt/qmake/MSVC 构建和人工交互验证。
- 替代关系：本计划覆盖既有文档中关于模板勾选、单项移除、用户手动调整模板优先级、顺序编号和同分优先级的当前行为说明；模板格式、模板保存、检测算法和设备流程继续服从现有有效计划与已验证基线。

## 2. 目标

模板选择窗口只负责：

- 展示当前检测模式中的模板；
- 增加外部模板文件夹；
- 勾选一个或多个待移除的模板；
- 一次从当前检测方案移除全部已勾选模板引用；
- 确认或取消尚未保存的新增模板。

窗口固定显示四列：

1. 待移除；
2. 模板名称；
3. 完整路径；
4. 状态。

窗口操作区固定保留：

- 增加模板文件夹；
- 删除已勾选模板；
- 确认应用；
- 取消。

勾选框只表示本次批量移除选择，不表示模板是否应用。勾选和取消勾选只改变界面选择状态，不写设置；打开窗口和增加新模板时默认不勾选。点击“删除已勾选模板”并确认后立即保存一次，底部“取消”不恢复本次移除。磁盘模板文件夹始终保留。

“确认应用”保存表格中仍存在的全部模板路径，不根据勾选状态过滤。新增模板在“确认应用”后保存，点击“取消”不保存尚未确认的新增模板。

界面不显示模板编号，不提供模板优先级设置。

## 3. 检测选择规则

字库和二维码+三期模式继续评价本次运行中全部有效模板，最终使用定位分数最高的模板。

`TemplatePoseSelector` 只实现最高分比较：

- 无效定位结果不参与选择；
- 尚无有效候选时接收第一个有效结果；
- 新结果分数严格高于当前结果时替换当前结果；
- 其他情况不更新当前结果。

匹配结果使用现有 `float` 分数，不改成 `double`。不增加随机数、排序器、模板优先级字段、同分策略枚举或其他策略对象。分数相等时保持当前候选，不提供界面控制，也不设单独人工验收项。

## 4. 设置和数据边界

`wordTemplatePaths` 和 `barcodeWordTemplatePaths` 继续使用 `QStringList`，因为运行时需要持有多个模板路径。配置中没有独立的顺序或优先级字段，因此：

- `AppSettings::CurrentSchemaVersion` 不变；
- 不新增配置字段；
- 不编写迁移、回退或兼容分支；
- `setTemplatePaths()` 继续完成路径清理、绝对路径转换、大小写不敏感去重和单模板数量检查；
- 不新增排序步骤，也不把列表替换成会破坏模板与运行快照索引对应关系的无序容器。

“确认应用”按表格中的现有行收集全部路径；勾选状态不进入 `AppSettings`。路径列表只作为模板集合的线性存储和加载输入，不形成用户可配置的优先级合同。

批量移除固定使用一个复数接口：

```cpp
OperationResult removeTemplatePaths(
    DetectionMode mode,
    const QStringList &paths);
```

该接口从当前模式的正式路径列表中移除全部匹配项，然后只调用一次 `saveTemplatePaths()`。不增加批量事务类、删除策略或磁盘操作。

## 6. 明确保持不变的行为

- 单模板模式的正式设置仍最多保存一个模板路径。
- 多模板模式仍可保存多个模板路径。
- 勾选和取消勾选只选择批量移除范围，不改变模板应用状态。
- “确认应用”保存表格中仍存在的全部路径。
- 所有有效模板仍参与定位，不按列表首个成功结果提前结束。
- 定位分数最高的模板仍决定本帧使用的模板名称、目标文字、阈值和字符资源。
- 模板文件夹增加、合法性检查、无效模板提示和路径去重不变。
- 选择窗口的批量移除和当前模板区的单项移除都只修改路径引用，不删除磁盘目录。
- 两个入口共享 `removeTemplatePaths()`，每次用户操作只保存一次设置。
- 批量移除确认后立即生效；底部“取消”只放弃尚未确认的新增路径。
- 启动时模板准备流程不变。
- 模板格式、保存目录、字符切割、相机、PLC、统计、存图和结果显示不在本计划范围内。

## 9. 用户统一验证

用户在 Qt Creator 中执行 Run qmake 和 Rebuild 后验证：

1. 打开单模板和多模板选择窗口，表格只显示待移除、模板名称、完整路径和状态，所有复选框默认未勾选。
2. 勾选、取消勾选后直接关闭窗口，当前检测方案和磁盘文件夹均不变化。
3. 同时勾选多个模板并点击“删除已勾选模板”，取消确认提示后表格和设置均不变化。
4. 再次执行并确认，全部已勾选路径通过一次设置保存从当前模式移除，未勾选路径继续保留，磁盘文件夹全部存在。
5. 批量移除成功后点击底部“取消”，重新打开窗口确认本次移除没有恢复。
6. 增加模板后点击底部“取消”，重新打开确认尚未应用的新增路径没有保存。
7. 增加模板后不论复选框状态如何，点击“确认应用”都保存表格中仍存在的全部路径。
8. 单模板模式增加新模板后点击“取消”，原模板仍然生效；再次增加并点击“确认应用”，只保存新模板。
9. 当前模板区的单项移除仍能正常使用，行为与批量移除一项一致，磁盘文件夹仍存在。
10. 字库和二维码+三期模式启动后，全部有效模板参与定位，分数最高的模板正常进入后续检测。
11. 回归模板编辑、模板保存、停止和再次启动，确认行为不受影响。

不构造同分样本，不把模板列表的显示先后作为检测验收条件。
