# OCRGangYin 计划索引

## 1. 用途

本文只负责选择当前任务应读取的计划，不复制各计划的详细步骤、功能合同或验收清单。新增计划时更新本索引，不修改项目 Skill。

更新时间：2026-09-04。

## 2. 权威顺序

1. 用户最新明确决定。
2. `重要限制.md` 规定所有任务共同遵守的项目级执行边界。
3. 覆盖当前任务范围的“进行中”计划。
4. 对应范围已完成计划形成的受保护基线。
5. `app/` 源码、工程文件和真实调用链用于确认当前行为事实。
6. 开发者指南、功能对照表和执行记录用于维护说明与历史证据。
7. 已替代、已完成或历史任务文档只用于追溯。

计划规定目标，源码证明当前事实。两者发生实质冲突时，不能用旧计划覆盖当前用户决定，也不能用当前错误实现否定已批准目标。

## 5. 任务路由

- 参数设定页顶部识别模式、完整纸巾粗糙度阈值设置迁移、PLC 工作模式默认连续触发或启动识别后的边栏保持：读取参数设定页控件迁移与运行交互调整方案；该方案在对应范围内覆盖右侧折叠导航栏方案和主窗口 UI 文件拆分方案的旧页面归属及启动成功自动收起结论。
- 主窗口 `.ui` 文件拆分、五个右侧内容页和三个模板弹窗的独立 Designer 编辑、生成 Ui 所有权、ViewBindings、页面回调或手写固定弹窗清理：读取主窗口 UI 文件拆分方案。该方案在对应范围内替代旧 UI 架构计划的单一 `.ui` 和保留 ViewBindings 结论，并替代右侧折叠导航栏方案的页面文件归属要求。
- UI、页面所有权、固定控件、主图像画布 `InspectionImageCanvas` 或模板向导：读取当前 UI 架构精简计划；涉及本次类型和路径结构时同时读取主窗口 UI 文件拆分方案。
- 点击“制作模板”后模板预览的最新帧读取、逐帧信号链精简、冻结图像来源和旧预览成员清理：读取模板预览帧链路精简方案。
- 主控操作台中相机、模板和检测按钮的分组，以及保存模板、分割字符模板迁移：读取主控操作台按钮分组界面优化方案，并保护当前 UI 架构精简计划、右侧折叠导航栏方案和统一 QSS 基线。
- 右侧折叠导航栏、内容抽屉、运行时开合和图像区显著判定栏：读取右侧折叠导航栏界面优化方案，并同时保护当前 UI 架构精简计划和统一 QSS 基线。
- 主程序二维码+三期结果本机 CSV 直写、远程发送端删除、严格 Schema 6、本机目录设置、CSV 写入失败 Fault 和退出链清理：读取二维码结果本机 CSV 直写主程序替换方案；该计划不修改 `tools/result_receiver/`。
- `tools/result_receiver/` 的接收、JSONL、CSV 同步、部署或后续处置：读取原二维码结果 TCP 传输与 CSV 接收方案及用户针对该目录的最新决定；不得把主程序本机 CSV 计划自动扩展到该目录。
- 模板格式、模板选择、设置 Schema 或运行准备：读取模板终局计划，并按需核对数据 Schema。
- 检测、Runtime、设备、PLC、线程或历史架构边界：先读当前源码和开发者指南；需要追溯时再读完成的终局方案与执行记录。
- 当前进度、验证状态和提交证据：同时核对有效计划、执行记录和 Git 状态。
- 新需求不属于任何有效计划：先形成独立计划文档并在本索引登记，不能把详细方案写进 Skill。

## 6. 项目级执行约束

- Agent 的实现范围、静态检查、构建分工和验证表述统一遵守 `重要限制.md`。
- 写入前检查分支、HEAD、工作区、暂存区和用户文件，不覆盖或混入无关修改。
- 提交、推送、合并、变基和历史改写只按当前计划与用户授权执行。
- 真实相机、PLC、机械动作和现场异常恢复没有实际验证时必须如实标记待验。

## 7. 维护规则

每份新计划应在开头明确：状态、权威范围、当前进度、替代关系和实施门禁。计划完成、被替代或重新启用时，同步更新本索引；历史正文保留，不把旧状态继续写入 Skill。
