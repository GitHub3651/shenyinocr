# 智能视觉检测系统

## 二维码+三期方案操作员使用说明

| 项目 | 内容 |
|---|---|
| 适用方案 | 二维码+三期检测 |
| 适用对象 | 生产操作员、换产操作员 |
| 文档版本 | 0.4（客户版） |
| 软件版本 | `[待填写：发布版本号]` |

> 本说明书只适用于“二维码+三期”方案。操作员按照本说明完成开机、模板选择、首件确认、连续生产、换产和停机即可。相机参数、模板制作、目标文字和 PLC 参数由调试员设置，操作员不要自行修改。

---

## 1. 开机前检查

1. 打开工控机电源。
2. 确认相机、光源、PLC 和输送设备已经通电。
3. 确认相机镜头前没有遮挡物。
4. 确认产品能够稳定经过检测位置。
5. 确认输送线暂时停止。
6. 准备一件合格首件和一件不合格样品。
7. 确认现场急停、安全门和防护装置处于正常状态。

`[截图占位：设备开机前现场照片]`

## 2. 启动软件

1. 双击桌面或发布目录中的软件图标。
2. 等待主界面完整显示。
3. 如果提示“程序正在运行”，关闭提示，使用已经打开的软件窗口。
4. 点击“打开相机”。
5. 等待图像区出现实时画面。
6. 检查画面：

   - 产品完整进入画面；
   - 二维码和日期/三期区域清晰可见；
   - 产品方向正确；
   - 画面没有全黑、全白或明显模糊；
   - 光源已经打开。

7. 点击“PLC通讯”。
8. 使用 PLC 硬触发生产时，确认状态显示 PLC 已连接。
9. PLC 未连接时，不要点击“启动识别”，联系调试员。

`[截图占位：主界面，标注“打开相机”“选择模板”“启动识别”“停止识别”“关闭相机”]`

---

## 3. 选择二维码+三期模板

### 3.1 选择模板

1. 确认软件当前没有正在识别。
2. 点击“选择模板”。
3. 在列表中找到当前产品对应的模板名称。
4. 检查模板状态显示正常。
5. 勾选当前产品模板。
6. 点击“确认应用”。
7. 返回主界面，查看当前模板名称。
8. 确认模板名称与当前产品一致。

### 3.2 多模板产品

如果现场已配置多个二维码+三期模板：

1. 点击“选择模板”。
2. 检查列表中的模板名称和状态。
3. 勾选本次生产需要使用的模板。
4. 点击“确认应用”。
5. 首件检测时确认软件显示的当前模板名称与产品版面一致。

### 3.3 没有模板或模板异常

1. 不要点击“启动识别”。
2. 记录模板名称和界面提示。
3. 不要删除或移动模板文件夹。
4. 联系调试员重新选择或恢复模板。

`[截图占位：选择模板窗口，标注模板名称、状态、勾选框和“确认应用”]`

---

## 4. 首件检测

每次开机、换产或调试员修改设置后，都要重新进行首件检测。

1. 确认“选择模板”中已应用当前产品模板。
2. 确认 PLC 已连接（使用硬触发时）。
3. 确认产品位于固定检测位置。
4. 确认二维码和日期/三期区域在画面内。
5. 点击“启动识别”。
6. 如果弹出“存在未应用参数”：

   - 需要使用新设置时，点击“取消”，联系调试员完成设置；
   - 不需要使用新设置时，点击“继续运行”。

7. 等待状态显示“正在识别”。
8. 放入一件合格首件。
9. 等待结果显示。
10. 检查判定结果是否为“正确”或“OK”。
11. 检查识别内容是否显示正常。
12. 检查结果图中的二维码区域和日期/三期区域框线是否覆盖正确。
13. 点击“停止识别”。
14. 放入一件不合格样品。
15. 再次点击“启动识别”。
16. 等待结果显示“错误”或“NG”。
17. 点击“停止识别”。
18. OK 样品和 NG 样品均符合现场标准后，才开始连续生产。

## 5. 正式生产

### 5.1 开始连续生产

1. 完成第 4 节首件检测。
2. 确认模板名称、产品版面和当前批次一致。
3. 确认状态显示“正在识别”。
4. 按现场输送方向连续放入产品。
5. 观察图像是否随产品刷新。
6. 观察“判定结果”是否持续更新。
7. 观察“识别内容”是否正常显示。
8. 观察“识别总数”和“不合格数 (NG)”是否持续更新。
9. 启用图像保存时，按现场规定查看保存目录是否有新图像。
10. 发现连续 NG、图像停止刷新、PLC 报错或相机断开时，立即停止送料。

### 5.2 处理单件 NG

1. 看到“错误”“NG”或二维码不可读提示时，停止送料。
2. 取出当前 NG 产品并单独放置。
3. 记录发生时间、产品编号和界面提示。
4. 查看结果图，确认二维码和日期/三期区域是否完整进入画面。
5. 重新放入一件产品进行复测。
6. 如果复测仍为 NG，点击“停止识别”。
7. 联系调试员检查模板、产品位置和图像质量。

### 5.3 查看生产统计

1. 查看“识别总数”。
2. 查看“不合格数 (NG)”。
3. 查看“合格率”。
4. 查看“耗时 (ms)”。
5. 交接班时记录以上数值。

### 5.4 清零统计

1. 点击“停止识别”。
2. 记录当前班次统计。
3. 如需清零总数，点击“识别总数”右侧的“清零”。
4. 如需清零 NG 数，点击“不合格数 (NG)”右侧的“清零”。
5. 按提示确认。
6. 检查对应数值是否变为 0。
7. 点击“启动识别”后重新开始计数。

---

## 6. 图像保存查看

图像保存选项由调试员设置，操作员只查看结果：

1. 点击“图像设置”。
2. 查看“图像保存”当前选项。
3. 查看“图像保存路径”。
4. 识别停止后打开保存路径。
5. 在 `ok` 文件夹查看合格图像。
6. 在 `ng` 文件夹查看不合格图像。
7. 需要报修时，复制对应时间的 NG 图像和结果截图。
8. 不要删除、移动或重命名保存目录中的图像。

`[截图占位：图像设置页中的保存选项和保存路径]`

## 7. 换产品和换模板

换产品前必须停止识别。

1. 停止送料。
2. 点击“停止识别”。
3. 等待状态变为空闲或已停止。
4. 点击“选择模板”。
5. 取消当前不使用的模板勾选。
6. 勾选新产品对应的二维码+三期模板。
7. 点击“确认应用”。
8. 返回主界面检查模板名称。
9. 检查新产品的二维码、日期/三期区域是否完整进入画面。
10. 如果新产品目标文字发生变化，不要自行修改，联系调试员。
11. 点击“启动识别”。
12. 先检测一件 OK 样品。
13. 再检测一件 NG 样品。
14. 两件样品结果正确后恢复连续生产。

`[截图占位：换产时模板选择和“确认应用”操作]`

## 8. 正常停机

1. 停止送料。
2. 等待检测区内的产品处理完成。
3. 点击“停止识别”。
4. 等待状态显示已停止。
5. 记录班次统计和异常产品数量。
6. 点击“关闭相机”。
7. 等待实时画面停止。
8. 关闭软件窗口。
9. 按现场设备规程关闭工控机及相关设备电源。

## 9. 常见提示处理

### 9.1 “请先打开相机”

1. 点击“打开相机”。
2. 等待实时画面出现。
3. 再点击原来的操作按钮。
4. 仍无法打开时联系调试员。

### 9.2 “请先连接 PLC”

1. 停止送料。
2. 点击“PLC通讯”。
3. 查看 PLC 是否显示已连接。
4. 未连接时联系调试员。
5. 不要自行修改 PLC 连接参数。

### 9.3 “请先选择模板”

1. 点击“选择模板”。
2. 选择当前产品的二维码+三期模板。
3. 点击“确认应用”。
4. 重新点击“启动识别”。
5. 列表没有模板时联系调试员。

### 9.4 “模板状态异常”或“二维码+三期模板预检失败”

1. 点击“停止识别”。
2. 记录模板名称和提示内容。
3. 不要删除、移动或重命名模板文件夹。
4. 联系调试员重新选择或恢复模板。

### 9.5 “二维码不可读”

1. 停止送料。
2. 检查二维码是否完整进入画面。
3. 检查产品是否放反、偏移或倾斜。
4. 清除产品表面可能遮挡二维码的异物。
5. 重新放置一件产品测试。
6. 仍然不可读时点击“停止识别”，联系调试员。

### 9.6 “读码器不可用”

1. 点击“停止识别”。
2. 记录提示内容和发生时间。
3. 不要反复重启或替换软件文件。
4. 联系调试员处理。

### 9.7 日期/三期识别错误

1. 停止送料。
2. 检查日期/三期区域是否完整进入画面。
3. 检查产品方向和位置。
4. 重新放置一件产品测试。
5. 仍然错误时点击“停止识别”，联系调试员。

### 9.8 连续 NG

1. 停止送料。
2. 点击“停止识别”。
3. 检查当前模板名称是否正确。
4. 检查产品是否在固定检测位置。
5. 保存一张 NG 结果图（如果已开启图像保存）。
6. 联系调试员处理，不要连续修改参数。

### 9.9 图像不显示或画面停止

1. 停止送料。
2. 点击“停止识别”。
3. 检查相机电源和网线指示灯。
4. 联系调试员检查相机。
5. 未确认相机恢复前，不要继续生产。

### 9.10 “系统故障－识别已停止”

1. 立即停止送料。
2. 检查输送线和剔除机构状态。
3. 记录故障原因、时间和当前模板名称。
4. 联系调试员处理设备、输送线和故障期间产品。
5. 重启软件。
6. 用一件 OK 样品和一件 NG 样品复测。
7. 复测通过后再开始生产。

### 9.11 图像保存失败

1. 停止送料。
2. 记录提示内容。
3. 不要修改或删除保存目录中的文件。
4. 联系调试员检查保存路径和磁盘空间。

## 10. 操作员不要修改的内容

以下内容由调试员或维护人员设置，操作员只检查，不自行修改：

- 模板框线、二维码区域和日期/三期区域；
- 目标文字和字符模板；
- 图像合格阈值；
- 相机曝光、增益、旋转和颜色通道；
- PLC IP、Rack、Slot 和触发参数；
- 剔除距离、剔除时间和剔除位置；
- 图像保存范围和保存路径；
- 软件安装目录、授权文件和读码器文件。

需要修改时：

1. 点击“停止识别”。
2. 停止送料。
3. 记录需要修改的项目。
4. 联系调试员。
5. 修改完成后重新做 OK/NG 首件确认。

## 11. 操作员一页检查卡

### 开机

- [ ] 工控机、相机、光源、PLC 已通电
- [ ] 产品位置正常，镜头无遮挡
- [ ] 软件已启动
- [ ] 已点击“打开相机”并看到实时画面
- [ ] PLC 硬触发生产时已确认 PLC 连接
- [ ] 已选择二维码+三期模板

### 首件

- [ ] 已点击“启动识别”
- [ ] OK 样品结果正确
- [ ] NG 样品结果错误
- [ ] 二维码区域和日期/三期区域框线正常

### 连续生产

- [ ] 状态显示“正在识别”
- [ ] 图像持续刷新
- [ ] 总数和 NG 数持续更新
- [ ] NG 产品已取出并记录
- [ ] 没有连续 NG 或故障提示

### 停机

- [ ] 已停止送料
- [ ] 已点击“停止识别”
- [ ] 已记录班次统计
- [ ] 已点击“关闭相机”
- [ ] 已正常关闭软件
