# Stage 0固定样本说明

固定样本用于从现有界面入口记录重构前行为，不用于推测或重新定义OK/NG。

每种检测模式至少登记：

- 一张当前程序判为OK的图像；
- 一张当前程序判为产品NG的图像；
- 一张缺模板、读码失败、无定位、空图或无目标等失败输入；
- 当前识别文本、Overlay要点、总数/NG/合格率增量、实际存图文件、PLC写入序列和关键耗时。

真实图像、模板目录、PLC与相机结果需要用户在现有程序中确认。没有用户证据时一律记为“待用户验证”，不得声称Stage 0已通过。

2026-08-09用户明确接受缺少人工样本的风险，并要求先按源码事实继续架构迁移。
因此本清单保留“待用户验证”状态供后续补录，不把延期改写成通过，也不用于
证明检测准确率、硬件副作用或性能已经保持。
